# sketch_260307b Video Ideas

This sketch is a good base for YouTube content because small changes in population, age, and reproduction can create very different outcomes.

## Strong Video Topics

1. Which species survives?
   Keep most settings equal and change one variable to see which group wins.

2. The minimum age trap
   Test whether a group with delayed reproduction can survive against a faster-breeding rival.

3. Baby boom vs extinction
   Increase offspring count and watch when growth becomes stable versus when it causes collapse.

4. Short life vs long life
   Compare fast-breeding short-lived particles against slow-breeding long-lived particles.

5. Does starting population decide the winner?
   Try identical groups except for starting population and see whether the larger group always dominates.

6. Perfect balance experiment
   Give both groups the same numbers and see how much randomness alone changes the result.

7. One tiny change, huge outcome
   Change one value by a small amount, such as offspring from 1 to 2, and compare the graphs.

8. Can two species coexist for a long time?
   Search for settings where neither side goes extinct quickly.

9. The comeback experiment
   Start one group weaker in population but stronger in lifespan or reproduction and test whether it can recover.

10. Population explosion challenge
    Push the settings toward runaway growth and see which setup hits the population cap fastest.

## Series Ideas

### 1. Survival Lab
Each episode tests one hypothesis, such as whether lifespan matters more than birth rate.

### 2. Red vs Blue Championship
Create a bracket of parameter sets and let them compete until one strategy becomes the winner.

### 3. Chaos From Simple Rules
Focus on how tiny changes in the inputs produce completely different patterns and graphs.

### 4. Building a Digital Ecosystem
Use the sketch as the base of a longer series where you keep adding mechanics over time.

## Parameters Worth Exploring

1. Population asymmetry
   Example: 10 vs 50, or 20 vs 100.

2. Reproduction asymmetry
   Example: offspring 1 vs 3.

3. Lifespan asymmetry
   Example: max age 5 vs 20.

4. Delayed maturity
   Example: min age 0.5 vs 8.

5. Tradeoff setups
   Give one group high offspring but short lifespan, and the other low offspring but long lifespan.

## Good Video Angles

1. I changed one number and the whole ecosystem collapsed.
2. Can the weaker species survive?
3. Which matters more: birth rate or lifespan?
4. This simulation looked balanced, but randomness took over.
5. I tried to build a stable ecosystem.

## Simple Recording Format

1. Start with a clear question.
2. Show the input values on screen.
3. Run the simulation and let the graph tell the story.
4. End with a short conclusion about why that result happened.
